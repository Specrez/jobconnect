### Job Connect — Job Recruitment Web Platform

Job Connect is a full-stack web-based recruitment platform designed to connect job seekers with employers through a centralized and user-friendly system. The platform provides separate role-based functionalities for job seekers and employers, allowing users to efficiently manage the recruitment process.

Job seekers can create and manage their profiles, browse available job opportunities, view detailed job descriptions, and submit applications for suitable positions. Employers can create and manage job postings, review submitted applications, and manage recruitment-related information through dedicated dashboards. The system uses role-based access to ensure that users can access features relevant to their responsibilities.

The project focuses on providing a structured recruitment workflow while improving the accessibility and management of job opportunities and applications. It also demonstrates practical experience in full-stack web development, database management, user authentication, role-based authorization, and CRUD-based application functionality.

**Key Features:**

* Role-based dashboards for job seekers and employers
* User registration and authentication
* Job posting and management
* Job searching and viewing
* Online job application management
* User profile management
* Employer application management
* CRUD operations for jobs and user-related data
* Relational database integration
* Role-based access control

**Technologies:** HTML, CSS, JavaScript, PHP, MySQL
